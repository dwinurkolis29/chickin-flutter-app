Kebijakan Privasi

Terakhir Diperbarui: 4 Juli 2026

Kami di BroilerKu berkomitmen sepenuhnya untuk menjaga kerahasiaan dan keamanan data operasional peternakan Anda. Halaman ini menjelaskan bagaimana data Anda dikumpulkan, disimpan, dan digunakan.

1. Informasi yang Kami Kumpulkan

BroilerKu mengumpulkan data yang diperlukan untuk mendukung fungsi monitoring kandang dan pencatatan harian peternakan Anda:

  • Informasi Akun: Alamat email dan kata sandi saat mendaftar menggunakan Firebase Authentication.
  • Profil Pengguna: Nama peternak, nomor telepon, alamat, dan foto profil.
  • Data Kandang: Nama/tipe kandang, kapasitas, lokasi, dan foto kandang.
  • Data Recording Harian: Catatan populasi, rata-rata berat ayam (gram), pakan habis (karung), dan tingkat kematian ayam (mortality).

2. Bagaimana Kami Menggunakan Data Anda

Seluruh data yang dikumpulkan hanya digunakan untuk kepentingan operasional dan peningkatan efisiensi peternakan Anda sendiri, dengan rincian:

  • Mengotentikasi identitas Anda untuk masuk ke dalam aplikasi secara aman.
  • Melakukan kalkulasi otomatis Feed Conversion Ratio (FCR) dan performa pertumbuhan ayam Anda.
  • Menyajikan grafik analisis visual tren performa kandang Anda.
  • Menghasilkan file laporan (format CSV atau Excel) untuk kebutuhan ekspor mandiri Anda.
  • Mengirimkan notifikasi pengingat lokal (jadwal pakan, vaksinasi, penimbangan) ke perangkat Anda.

3. Keamanan & Penyimpanan Data

Kami menggunakan infrastruktur cloud Firebase (Google Cloud) untuk menyimpan data secara aman secara online di Cloud Firestore. Untuk performa yang cepat dan mendukung penggunaan offline, kami juga menggunakan penyimpanan lokal (Hive) yang terenkripsi di dalam perangkat Anda.

Kami menerapkan standar keamanan terbaik untuk melindungi data Anda dari akses tanpa izin, kehilangan, atau penyalahgunaan.

4. Berbagi Data dengan Pihak Ketiga

Kami tidak pernah menjual, menukar, atau menyebarkan data pribadi maupun data operasional peternakan Anda kepada pihak ketiga untuk kepentingan komersial.

Penggunaan layanan pihak ketiga terbatas pada Google Firebase (Authentication & Cloud Firestore) untuk infrastruktur database yang aman.

5. Hak-Hak Anda atas Data

Anda memiliki kontrol penuh terhadap data Anda di aplikasi BroilerKu:

  • Anda dapat memperbarui, mengedit, atau menghapus data kandang dan recording kapan saja dari aplikasi.
  • Anda memiliki hak untuk meminta penghapusan akun secara permanen beserta seluruh data yang terkait dengannya.
